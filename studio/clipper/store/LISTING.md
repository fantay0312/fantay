# Fantay Web Clipper

## Listing text

**Name** — Fantay Web Clipper

**Summary** — Save webpages, design references, images and screenshots to your Fantay Library.

**Description** — Capture a whole page or selected element, collect images, take a visible-page or region screenshot, and extract a design-system reference. Export structured webpage captures for the Fantay Figma Import plugin. Start the Fantay desktop application before saving captures.

## Permissions

Page access and scripting support user-triggered capture. Tabs identify the selected page. Context menus provide the image capture action. Downloads save Figma JSON. Local storage retains the configured application address and toolbar preferences.
