# Fantay Web Clipper privacy information

Fantay Web Clipper reads the selected webpage and its referenced resources when you request a capture. Depending on the action, the result contains HTML, styles, images, a screenshot, a source URL or a Figma node tree.

Captures are sent to the application address configured in Advanced. The default address is `http://127.0.0.1:7456`. A custom remote address sends the capture to that service. Figma JSON downloads are saved through the browser's download feature.

The extension stores its application address, toolbar visibility, toolbar position and image-hover preference in browser extension storage. The Fantay application manages captured Library data.

Use the browser's extension management to remove the extension and its local settings. Manage saved captures in the Fantay Library.
