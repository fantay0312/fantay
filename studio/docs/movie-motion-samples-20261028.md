# 完整动画样片与主页一句话出片

## 样片

三套新风格都包含 3 个镜头、12 秒完整动画。预览视频位于 `apps/web/public/movie-samples/`，使用与正式出片相同的 HTML/GSAP 渲染流程。

- `signal-journey` / 信号成形：输入脉冲汇聚、路径分流、结果聚合。
- `paper-garden` / 纸上花园：种子落地、根茎生长、叶片及花瓣展开。
- `paper-city` / 城市醒来：蓝图描边、建筑逐一升起、电车与行人移动、镜头拉远。

每个镜头可保存独立 `visual`。图层支持归一化关键帧（位置、尺寸、缩放、旋转、透明度、路径描边），画面支持镜头运动。保存风格时一并保存 `demoShots`；再次使用保留完整镜头及运动数据。

路径描边使用 SVG 属性动画保留小数精度，避免 CSS 像素取整使路径突然完整出现。实际 GSAP 测试覆盖半程和完成进度。

## 主页流程

选择风格、输入创意后，主按钮为「一句话生成影片」。点击时只授予当前项目本次制作权限；另一入口「先看分镜」保留逐步确认流程。

DeepSeek 先读取影片，用 `fantay_movie_update_story` 修改已有镜头的文案与时长。该工具严格保留视觉图层、关键帧、镜头运动及素材，避免通过重写整个 JSON 丢失动画。随后 `fantay_movie_produce` 生成逐镜 PNG 并出片，`fantay_movie_wait` 返回实际运行状态。最终审片和交付仍由用户确认。

后端校验授权、内容版本与素材内容摘要；样张期间发生改动会停止本次制作。重复请求不会启动重复渲染。服务重启、过期授权或修改后的旧成片会返回中断状态。开始渲染前可取消自动流程；渲染开始后界面展示进度。渲染进度写入已限频。

风格卡片使用原位播放按钮，同一时间只播放一张卡片。卡片预览与选用风格为独立操作；已保存的自定义风格仍可使用实时预览。

## 实测

- DeepSeek Harness 继续作为默认测试代理，配套运行包版本为 `0.1.8`。没有调用 Claude Code 或控制 Claude 桌面端；Claude Code 可用性不受本功能禁用。
- 一次旧工具路径测试被权限策略拦住并主动停止，未开放终端。随后增加保留动画数据的专用文案工具并重新测试。
- 项目 `6dd308d5-28cd-4104-b56d-3170e735b08a` 从主页一句话自动完成分镜、逐镜 PNG、12 秒 MP4。分镜改为「灵感，是一粒种子」「向下扎根，向上生长」「让好想法开花」，三镜头视觉数据保留。状态为 `done`，`approvedRenderId` 为 `null`，没有自动签收。
- 最终引擎再次实测项目 `c8924570-8970-45cf-9219-e67dcfb439ce`：只在主页选择「城市醒来」并提交一次需求，DeepSeek 自动完成新文案、逐镜样张和 MP4，尾句改为「让构想成为日常」。真实输出为 1920×1080、30 fps、H.264、12 秒；留在待审片，没有自动生成交付包。
- 验证记录、逐段检查图及样片项目映射保存在 `.tmp/movie-motion-v2/`。
- 验证通过：动画后端 30 项、网页动画组件 11 项、视觉合约 3 项、DeepSeek 运行包 21 项；相关 TypeScript 检查与项目 `guard` 通过。390px 窄屏无水平溢出。风格卡片实测能直接播放、切换时暂停前一张。
