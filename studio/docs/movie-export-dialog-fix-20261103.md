## 保存与格式

原生主进程持有保存对话框选择的路径，界面只传不透明目的地句柄、项目和成片版本 ID。主进程通过受授权的项目 API 读取指定完成版本，保留 workspace identity；不接受界面提供的任意读取 URL 或写入路径。成片流式写到目标目录的临时文件，完成后替换目的文件；失败清理临时文件，保留已有目的文件。

MP4 为 H.264 / AAC。MOV 使用 FFmpeg 将这些流实际封装为 QuickTime 容器，并非修改扩展名。渲染记录保存独立的 `exportOptions`；CLI 的 `render` / `render-preview --file <path|->` 可传同一格式、尺寸和有理数帧率设置。
