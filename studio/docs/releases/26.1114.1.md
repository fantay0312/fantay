- 独立显示 TokenToSea 实际扣费、其他渠道报告费用和本地 Token 估算价值。估算不写入扣费字段，不触发支付。
- 使用 models.dev 公共价格表缓存，按精确模型名、输入、输出、缓存读取和写入估算。无法匹配、缺少缓存单价、1 小时缓存写入或阶梯价格不猜测。

- 仅保留用量元数据，不保存提示词、回答、工具输出或凭据；请求公共价格表不发送本地日志。

## 已知限制

- 本机全部指受支持且可读取的本地历史，不代表所有软件或账号的完整服务账单。
- Fantay 已登记的原生会话以 Fantay 记录为准；同一会话后来在外部续写的部分尚不能单独归属。
- 无法证明父历史边界的 Codex 分叉、缺少累计基线的续写、未支持的日志格式及超出扫描上限的文件标记为部分记录。
- 估算采用抓取时的公开单价，不是调用当时的发票价格；订阅抵扣、促销、不同服务层和税费不包含在内。
- 尚未进行 Windows 安装及公开更新源的端到端验证。
