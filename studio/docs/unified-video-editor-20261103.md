# 统一视频剪辑工作区 · 2026-11-03

用户要求取消独立的完整「Fantay 剪辑」，所有日常剪辑在项目的现有文件窗格内完成，并同时服务 AI 与人工操作、Windows 与 macOS。此决定取代此前“简易编辑器 + 显式打开原生完整版”的入口规则。

## 实现

- 复用 `MovieDocument`、React 时间线、主项目聊天、版本检查、原子保存和撤销重做，作为唯一编辑真源。
- UI、CLI、MCP 使用同一批量编辑接口。AI 接收所选片段与播放头上下文；用户可随时手动裁剪、跨轨移动、调整音量、速度、字幕与文字。
- 在现有界面内导入视频、音乐和图片，支持独立音频与文字叠轨、画幅/帧率调整、淡入淡出、直接导出。窄窗格保留“片段与项目调整”弹层，宽窗格停靠检查器。
- 预览使用同一份 HTML/GSAP 时间线；标准导出沿用 FFmpeg 预裁切/变速、逐帧合成和真实混音。原素材保留。MOV、ProRes/HEVC 等浏览器不兼容视频生成项目内 H.264 预览代理；导出使用原素材。
- 不再启动、构建或随 macOS 包分发独立原生编辑器。旧原生 API 仅保留不外开的兼容入口。
- FrameVelo 继续作为 HTML 动效的可选导出方式，其既有回退和色彩处理保留。

## 放大后的完整工作台

右侧编辑区达到 960 CSS 像素时自动切换布局并展开素材库，显示素材、预览、检查器三栏和更大的时间线。素材栏、检查器与时间线分隔条实际控制尺寸；缩回窄栏时恢复紧凑编辑和属性弹层，继续使用同一选区、播放头及文档。

- 素材分类、搜索、源预览、入出点选段、接到片尾或叠加到播放头。
- 精确时间码、逐帧、全屏预览、跨轨移动、裁前/裁后、切分、删除、合拢本轨、复制、分离音频、静音、锁定、吸附和缩放。
- 画面布局、画中画、旋转、裁切、曝光/对比/饱和/模糊/黑白；独立音频淡入淡出和重复配乐。
- 同轨相邻片段的交叉淡化、擦除、圆形转场；线性画面关键帧、推近/滑入/淡入预设。预览和导出使用共享渲染，切分保留运动姿态。
- 文字入场与逐字显示、原声转写、所选片段 SRT 导入导出、字幕字号/颜色/底色/描边和位置。
- 锁定片段由共享编辑入口保护，AI 与人工都不能直接修改；修订号冲突必须重读，避免覆盖另一方的改动。

当前标准输出为 SDR；素材上传单文件 256 MiB、渲染素材合计 256 MiB，每次渲染最多 128 个可听片段，最多 8 个层级轨道。高级原生工程的兼容限制仍适用。

## 旧工程

首次进入读取关联 `.palmier` 的最新 `project.json` 和 `media.json`，复制用到的媒体到宿主项目，并保留原件、原宿主稿和元数据备份。帧位置依照原有有理数时基转换；真正关联且时间一致的音画合并为一个可剪片段，裁剪、移动和变速保持同步，独立配乐继续作为独立音轨。只有转换、验证和原版本检查成功后才切换编辑真源。导入建立新的撤销基线，旧历史留在原件和迁移备份中。

当前导入活动时间线。其他时间线及尚不能直接表现的旧特效、逐词样式、裁切/透视等保留在原件和备份中并显示提示；缺失媒体、嵌套序列或超出轨道范围会停止导入，不以旧宿主稿覆盖。不能将此称为全部原生工程的无损迁移。统一编辑器当前标准导出为 SDR。

## 开源参考与实际使用

- [Shotcut/MLT](https://github.com/mltframework/shotcut)：参考多轨与媒体行为，保留为长期媒体引擎候选；本轮未引入 Qt/MLT 运行时。
