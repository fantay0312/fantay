# 从空白导演、预览和复用动画

## 原创入口

「从空白开始」不继承当前样例的图层或演示镜头。输入创意后，可选择先设计并保存风格，或一次完成影片。空白创作提示词要求 Agent 自己安排镜头事件、构图、图形、关键帧和镜头运动；已有完整风格复用才使用仅修改文案和节奏的工具。

镜头的 `direction` 记录画面与动作说明，与画面上的标题、字幕分开。完整风格快照保留画幅、各镜头的图层、时间与运动数据。

## 结构化创作

- `GET /api/projects/:id/movie/authoring-guide` 描述绘图与运动语言，不返回样片模板。
- `POST /api/projects/:id/movie/author` 接受 `expectedRevision`、允许的风格字段和完整镜头。`shots.mode=replace` 初始化分镜，`upsert` 按 ID 更新或添加镜头。
- Harness 提供 `fantay_movie_guide`、`fantay_movie_author`；MCP 提供 `movie_authoring_guide`、`author_movie`；CLI 提供 `movie guide`、`movie author --file`。它们使用同一后端与项目授权。
- 内容变更在项目锁内原子保存，清除旧样张和审批；保留已授予的本次 production 权限。调用方不能通过 author 改审批、成片或授权字段。

工具只提交受限的图层与关键帧，不执行任意 HTML、脚本、网络或终端命令。错误会指出无效字段或数值范围，便于 Agent 修订。

## 预览与保存

动态预览采样每镜 15%、50%、85% 的状态。单次最多 6 镜，长分镜使用 `shotIds` 分批，覆盖记录按内容版本合并。保存原创风格要求所有镜头已有当前版本的动态预览。服务端维护原创状态，修改风格 ID 或开拍模式不能绕过预览要求。

保存时冻结使用到的媒体与来源回执，再改写快照路径，后续编辑原素材不改变已保存风格。DeepSeek 不能直接写入样张、出片或风格快照目录。主页复用时，风格媒体和逐镜媒体都重映射到目标项目。
