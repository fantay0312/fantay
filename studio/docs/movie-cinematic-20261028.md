# 实体画面、材质与镜头衔接

## 目标与参考

用户认为上一版「纸上奏鸣」仍是线框演示。本次参考本地 Lemo 视频中的彩色材质网格、纸片体积和投影，改善实际成片画面；沿用 Fantay 页面结构与本地制作流程。

## 绘图能力

- `fill` 与 `strokeColor` 独立，填充和轮廓可同时存在。旧 `color/stroke` 语义保留。
- `gradient` 支持线性或径向的 2–8 个受限颜色停点；`shadow` 支持颜色、透明度、偏移与模糊；`texture` 提供确定性的纸纹或颗粒，不加载外部图片。
- `group/parentId` 将多部件组成同一物体；最多四层、禁止循环。全画幅组内保留百分比坐标。`origin` 控制铰链/旋转中心。
- `rotationX/Y`、`scaleX/Y`、运动模糊及固定缓动扩展，用于纸片折转、蓄力、回弹和稳定。
- 参数化 `gear` 在本地生成实体齿形与轴孔，避免模型调用终端计算坐标。

所有颜色和数字继续经过解析器检查，不接受任意 CSS、SVG 标签、外部 URL 或脚本。投影绘制不受图层边框裁切；画面范围仍由镜头裁切。

## 时间轴

`cut` 直接衔接；`crossfade`、`wipe`、`iris` 在镜头边界后保留上一镜的最终姿态，再揭示下一镜。转场时间不会增加影片总长。每镜可以设置背景和前景颜色。素材视频在过渡期间冻结结束帧。

未指定入场的图层保持正常显示；不再对全部图层强制应用相同的 0.7 秒淡入。相机与物体关键帧仍共用可逆的确定性时间轴，拖动预览和最终渲染使用相同代码。

动态样张除每镜前/中/后外，增加进入转场中点，便于检查衔接。预览缓存版本升级，避免复用旧渲染器样张。

真实渲染器会按 `data-duration` 裁切元素，因此过渡保留时间也写入场景和视频元素的显示时长；视频原播放时长由 `data-play-duration` 独立记录。实际红/蓝画面测试在过渡中点得到 `(128,0,128)`，确认两镜叠化而非露出背景色；总长仍为 8 秒。

## 导演要求

新原创/改风格流程默认要求可识别的实体主体、明暗和接触阴影，减少空白开场与小字说明；通过同一物体、运动方向、形状或遮挡连接镜头。先完成整部影片，再集中检查与修订，避免无休止的局部校准。

本轮测试继续使用 DeepSeek。Claude Code 保留可用，不进行测试或调用。最终审片与交付仍由用户确认，改动仅在本地。

## 实测结果

从主页空白入口提交一次 16 秒实体纸雕音乐盒需求，DeepSeek 自主生成六镜、完成预览检查、保存「奏鸣·纸雕电影」并自动生成 MP4。项目为 `43b9c398-948c-4b64-88c5-b83cd13cf8b5`，保存风格 ID 为 `personal-cc34531f-4097-4793-9fb8-1fdb47bf337a`。

实测发现导出器按元素时长提前隐藏转场底图。修复显示时长后，在同一工作台重新渲染 v2，保留 AI 原创的全部图形与动作。最终文件为 `.tmp/movie-cinematic/sonata-paper-cinema.mp4`，H.264、1920×1080、30fps、16 秒，render ID `ac1789bb-84e0-4bac-876d-8d16a9914cc0`。审片通过与交付记录仍为空。

实体画面、宏观机构、纸带折鸟、翼幕遮挡、星空收尾均已检查；切点帧在 `transition-contact.jpg`，全片抽帧在 `final-contact.jpg`。动画后端 45 项、网页组件 12 项及相关类型检查通过；另用真实渲染器完成红/蓝场景叠化像素检查。
