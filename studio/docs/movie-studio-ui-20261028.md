# 动画工作台页面整合

用户否定了「工作台卡片 → 弹窗 → iframe 内再显示整套应用」的呈现，并要求首页联动。本次使用现有 Fantay 视觉体系重排页面，不改全局设计令牌。

## 行为

- `MovieChatCard` 整张卡可点，直接进入 `/movies/:projectId`，不创建 Dialog 或应用 iframe。动画画面的 sandbox iframe 保留，仅负责作品预览。
- 具体作品路径由统一 router 管理，保留旧 `?project=` 深链接，支持正常前进、后退、刷新。
- 首页「动效设计」入口携带已输入的 brief 和设计系统选择进入动画创建页；模型控件仍使用相同配置。首页草稿保留，附有文件、目录或其他上下文的原创建路径保留，避免丢失附件与授权上下文。
- 已知动画项目从侧栏最近项目、首页项目入口打开时直接进入制作页。
- 取消右侧默认空白对话列。预览与镜头时间线位于左侧，制作设置和 AI 对话在右侧切换。切换面板不会中断已挂载的对话。
- 片库上方使用统一创作输入区，四种开拍方式使用紧凑切换，风格卡展示不同样例标题。
- `next.config.ts` 关闭 `devIndicators`，去掉用户界面右下角的 Next.js 开发工具入口。

## 首页创作模式与 Lemo 流程复刻

后续要求把创作留在首页，本次进一步新增 `/create/animation` 与 `/create/animation/:projectId`。首页输入框的「动效设计」将创作想法带入这个模式，侧栏仍保持首页选中；`/movies` 独立入口兼容保留。路由间共用一个 `MovieStudio`，不创建第二套项目或模型配置。

- 片库展示已有影片的实际预览、风格、时长和制作状态，提供「新建影片」。
- 新建时保留从库里选、改一个风格、用我的风格、从空白开始；风格支持搜索和右侧详情。
- 「创建并生成分镜」与「根据需求生成分镜」向现有模型发送显式任务；`SideChatTab` 等历史加载完成后只提交一次，错会话或不可用模型不发送。
- 分镜、样张、渲染沿用同一文件与真实 MP4 管线。AI 不自动确认分镜、样张或最终审片。
- 审片可切换成片版本，点击镜头或意见定位；输入意见时固定时间点并暂停视频。其他版本未处理意见不会被过滤后隐藏为“已全部解决”。可用当前模型按意见修改。
- 固化相同风格不再重复添加；个人风格必须选择已有快照。MCP 的 `sourceProjectId` + `styleId` 可复用相同快照。
- MCP 新增 `get_movie_task` 提供分镜、风格和修改意见上下文，实际修改由宿主模型调用 `save_movie` 完成。`open_movie_studio` 返回首页模式链接和 `/movie-app` 轻量嵌入链接；嵌入页省略全局侧栏、工作区标签、宠物和首页促销弹窗。
- 异步导航完成后才提交新影片状态，避免创建时被旧路由清空。返回片库会取消过期读取；重新打开运行中的会话会同步持久化状态，拒绝重复生成。

参考视频只作为布局和工作流依据，没有导入其品牌、素材或声称具备其全部风格数量。本地现有 6 种内置风格加用户保存风格，代码动画为主，兼容项目内图片和视频素材。

### 本次实际验收

项目 `a650c57b-7961-4de2-9bc5-fd7575faa025`：从首页输入创作想法，经「动效设计」进入首页内的动画模式，选择纸上电影，实际向模型发送任务。Claude Code 一次请求未返回而取消；随后 DeepSeek Harness 生成三个各 2 秒的镜头，自动同步到工作台。通过页面固化风格、确认分镜和样张、渲染 v1 后，在 0 秒添加修改意见，点击「按意见修改分镜」。DeepSeek 确实把第一镜字幕改为「灵感，从纸上开始。」，保存后解决批注，没有自动确认或渲染。页面再次确认并生成 v2，已验证旧版不能通过当前审片，v2 审片通过并生成 ZIP。

实际下载文件位于 `.tmp/movie-reference-v2/home-film.mp4` 与 `home-film-delivery.zip`。ffprobe 验证 MP4 为 6.000 秒、1920×1080、H.264；ZIP 包含成片、HTML 动画源文件、GSAP、影片 JSON 和说明。技术验收不代表用户对创意签收。

验证：6 个相关 Web 测试文件共 69 项通过，2 个 Movie daemon 测试文件共 9 项通过；Web/daemon 类型检查、项目 guard 通过。补充回归覆盖延迟导航、过期深链、恢复中的任务拒绝重复提交、个人风格复用、MCP 两种宿主消息格式。桌面完整流程及无外壳嵌入页已检查；390 像素断点的 DOM 宽度与页面内容宽度均为 390，无页面横向溢出。
