### 必须保留的时间戳修复

原版在本机 FFmpeg 9 上会生成“帧数正确、视频时长错误”的 MP4：纸雕样例 480 帧却只有 **0.071159 秒**，花园影片的视频轨只有 **0.058854 秒**，音频轨仍为 9.7 秒。原版检查帧数和容器时长不足以发现后者。

本地补丁将 `setts` 从改写 `time_base` 改为在原时基中计算 `N * frameTime / TB`；读取并校验视频轨自身的时长。修复不重编码已有画面。修复后的完整样例分别为 480/291/180 帧、16/9.7/6 秒，30fps。额外实测 29.97fps 的 30 帧输出为 **30000/1001 fps、1.001000 秒**。上游单元/MCP 测试 **76/76 通过**；未声称运行了上游完整集成测试集。

## 样例与方法

源文件均复制到隔离目录，未修改已有工程：

1. **纸雕动效**：`.tmp/movie-cinematic/final-source.html`，16 秒、1920×1080、30fps、480 帧。缺失的同目录 GSAP 从现有预览工程补齐，同为 3.14.2。
2. **花园影片**：现有 `movie-94a678e0-260a-4794-b7cc-c44d36a4e69c` 工程，9.7 秒、291 帧，四段实拍、中文字幕与音轨。
3. **切片实拍**：现有 `movie-b6eb22d7-977c-4b57-abe9-da665a3cc72d` 工程，6 秒、180 帧，覆盖 2 秒处的片段连接。
4. **字幕隔离样例**：从花园副本移除 `<video>`，保留原字幕时间轴和音轨。该项是诊断用派生样例，**不是未经修改的第四个真实工程**。

基线调用当前 `renderDeterministicFrames`，逐帧 Electron 截图、PNG 落盘、libx264 编码。候选复用当前 HyperFrames 时间定位桥和音频混合函数，只替换捕获/视频编码；关闭视频代理和多 worker。两侧均使用同一 FFmpeg 9.0.1，以便隔离渲染差异；这不是对已安装应用全部运行配置的复现。FrameVelo 的区间自检阈值为 40 dB，失败区间允许截图回退。

渲染串行执行。耗时包括子进程启动和混音；累计 CPU 时间与峰值进程树 RSS 每 200ms 采样，不能等同于整机物理内存、能耗或实时 CPU 百分比。前一轮是故障发现轮，后一轮是修复后完整重测；以下为后一轮单次结果，**不是三轮中位数，也不是跨机器结论**。

| 样例 | Electron → FrameVelo 耗时 | 累计 CPU 秒 | 峰值 RSS MB | 结论 |
|---|---:|---:|---:|---|
| 纸雕动效 | 36.45 → 10.12 秒 | 41.93 → 12.68 | 1398 → 979 | 约快 3.60 倍；仍需解决画面一致性 |
| 花园影片 | 24.58 → 23.14 秒 | 19.22 → 28.19 | 1249 → 1154 | 提速很小，CPU 增约 47% |

## 画面与声音验收

帧序列按帧号对齐。Electron 的 PNG 含显示器 ICC 配置；直接忽略 ICC 会扩大色差，因此先用颜色管理转换到 sRGB，再与候选解码 RGB 逐帧比较。尝试给 Electron 传 sRGB 开关后，输出仍带原显示器配置；最终仍以 ICC 转换后的 PNG 为参考，没有把未校正结果当结论。

| 样例 | RGB PSNR 平均 / 最低 | SSIM 平均 / 最低 | 文件大小 Electron → FrameVelo |
|---|---:|---:|---:|
| 纸雕动效 | 38.17 / 33.96 dB | 0.9843 / 0.9739 | 2.39 → 16.95 MB |
| 花园影片 | 33.72 / 30.14 dB | 0.9574 / 0.9298 | 2.33 → 13.80 MB |
| 切片实拍 | 31.24 / 18.28 dB | 0.9145 / 0.8661 | 1.38 → 6.10 MB |
| 字幕隔离 | 36.08 / 33.70 dB | 0.9974 / 0.9967 | 0.19 → 0.24 MB |

- 检查了字幕出入、切镜前后及片段连接处的并排帧。样张中的中文字形和字幕内容完整；字幕隔离样例结构相似度较高。
- 三个有声样例两侧解码到 48kHz 双声道后 **逐采样完全一致**：花园/字幕各 465600 个双声道样本，切片 288000 个；最大绝对差与 RMSE 均为 0。
- 修复后视频帧数、视频轨时长和音频轨时长吻合；这不等于每个实拍帧都与原路径完全一致，切片样例的低相似度帧仍不通过。
- 在切片样例的输出帧 101，画面烧录计数显示旧路径取到源帧 100（3.333 秒），新路径取到源帧 101（3.367 秒）。这是确定的一帧定位差异；必须先核定源片时间与取帧契约，不能把差异全部归因于 FrameVelo 画质。并排证据为 `fixtures/splice/worst-frame.png`。
- 未达到采用的平均 40 dB 画面一致性参考线。RGB 指标比上游默认 YUV PSNR 更严格，不能把本表直接与上游表格相减；也不能因此跳过可见色彩差异和切片异常。
- 默认码率不同，候选纸雕文件约为基线 7 倍。没有把当前结果包装成同码率/同文件大小性能比较。
