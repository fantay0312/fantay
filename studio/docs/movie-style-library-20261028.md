# 动画风格库、素材库与设计系统联动

> 2026-10-29 界面规则更新：视频／动画项目使用独立的“动画风格”入口，不能以网页设计体系作为默认风格。新影片不继承全局网页 `designSystemId`，风格界面不再提供网页体系绑定选择。下文关于 token 链接的内容是历史底层能力记录，不代表当前桌面端的默认制作流程。当前界面与验收见 `desktop-ui-audit-20261029.md`。

## 数据与呈现

`MovieStyle` 扩展为可编辑的图层配方：百分比坐标、色块、网格、路径、文字、图片/视频图层、单层入场与漂移动效、主文案区域、整体转场。输入只接受受限枚举、数值和 SVG 路径数据，不执行任意 HTML/CSS/脚本。

八种内置风格使用不同配方：几何版式、杂志编辑、信号字幕、技术蓝图、有机波形、极简排版、纸片拼贴、影像手记。素材图层未绑定图片时显示原创抽象占位；导入后替换为真实素材，不把占位描述为外部图片。

后续加入三套带完整逐镜动画的样片，内置总数为 11。保存风格现包括完整 `demoShots`，可复用镜头动作和相机轨迹。详见 [完整动画样片与主页一句话出片](./movie-motion-samples-20261028.md)。

## 连接已有库

- 素材继续通过既有只读归档服务搜索，导入通过既有复制服务进行，保留来源、许可、复制回执。网页“加入风格”和“仅参考”分别复制文件或只记录来源。
- 设计系统从已有授权入口读取 canonical `tokens.css`，解析 `--bg`、`--fg`、`--accent` 与字体变量；绑定保存颜色/字体快照和源文件摘要，不把任意 CSS 注入渲染器。
- 保存风格保留完整图层、素材路径、素材证据和设计系统来源。跨项目复用先检查源项目权限，再复制实际资源与回执，避免沿用失效的旧项目路径。
- 交付包包括使用到的风格素材和 `STYLE-SOURCES.txt`，完整许可正文可随引用传递。

## Agent 与 MCP

DeepSeek 受限工具增加 `fantay_movie_style_catalog`、`fantay_material_search`、`fantay_design_systems`、`fantay_movie_style_link` 和 `fantay_movie_preview`。它们固定到本地服务和当前影片，不能借此访问任意 URL、项目或 shell。预览通过本地 HyperFrames `snapshot` 生成真实 PNG；Agent 可用 `read_image` 检查后，再调用保存风格工具。

MCP 提供相应的风格目录、素材搜索、设计系统列表、关联与 PNG 预览工具。Claude Code 保持可用，但本次不测试它。

## 验证记录

图层配方隔离与渲染结构、设计系统变量解析、素材跨项目复制、许可保留、预览缓存和符号链接边界均有定向测试。实际素材复制已经验证文件 SHA-256 相同、目标路径独立；基于新配方的 PNG 预览已生成。后续实测的具体作品与截图放在 `.tmp/movie-reference-v2/`。

完整实测已完成：DeepSeek 在项目 `6f8d7005-7c90-4d9a-9c33-f6656459ee51` 自行检索素材、创建“构造编辑室”的 13 图层配方、导入真实 ViteJS SVG、生成并读取 PNG、修订后保存风格。最初发现渲染目录无法访问上级素材，已修复为在渲染目录内复制素材，并补充防符号链接和缓存一致性检查。

通过真实 MCP 客户端将此风格复用到项目 `73b491fa-34f0-494a-bc8a-92605cddf29a`，实际复制了素材和许可回执，生成正确 PNG，并通过网页完成 6 秒、1920×1080、H.264 视频与 ZIP 交付。文件位于 `.tmp/movie-styles/`，包含 `reused-style.mp4`、`reused-style-frame.png`、`reused-style-delivery.zip` 和 `personal-style-library.png`。这些审批为技术验证，不是用户创意签收。

新功能允许基于设计系统快照继续调色和调整图层；`designSystem` 记录来源，不会将后来手调的颜色宣称为原始 token。使用自定义字体时仍遵循浏览器的字体可用性与回退行为。
