# 桌面端视频与动画完整流程验收（2026-10-29）

本次使用当前已安装的 Mac ARM64 桌面版本，实际操作界面并检查导出文件。代码动画与视频剪辑两条流程均通过。未改动业务代码，未调用付费视频模型，未提交、推送或部署。

## 代码动画

从“新建视频与动画”选择“纸上花园”，播放风格卡片并创建 3 镜头、12 秒的测试影片。在独立“动画风格”视图中切换到“蓝图叙事”并保存，确认原分镜内容保持；再切回“纸上花园”，保存为个人风格。

编辑第一镜头标题并新增字幕，一次应用后验证撤销和重做均恢复完整内容。随后通过界面确认分镜、生成 9 张真实样张、开始制作、进入审片并播放成片，再生成并下载完整交付包。

- 输出：12 秒、1920×1080、30 fps、H.264 MP4。
- 抽查 2、6、10 秒，确认种子、枝叶、花朵三个阶段及修改后的文字进入成片。
- 交付 ZIP 可完整解压，包含 MP4、动画 HTML 源文件、GSAP、字幕、影片文档与来源说明。
- 这次没有添加配音或配乐，动画样片没有音轨。

## 视频剪辑

在独立的桌面验收实例中，通过视频选择器上传本地 4 秒测试视频，创建视频项目并加入时间线。界面完成播放、在 1.5 秒切分、撤销、重做、裁短第二段、前移片段以及撤销前移。

最终时间线保留原片的 `0–1.5s` 和 `2.5–4s`，通过“导出预览 MP4”生成实际 3 秒成片。

- 输出：3 秒、1920×1080、30 fps、H.264 视频和 AAC 音频。
- 解码检查通过，音轨不是静音；峰值约 −14.8 dB。
- 导出第 2 秒对应原片第 3 秒，画面中的时间码确认裁切偏移正确。
- 同一时刻的桌面预览与导出帧对比 SSIM 为 0.966；检查包含窗口缩放与有损视频编码差异。
- 关闭并重新启动验收实例后，两个片段、原片入点、渲染记录均保持一致。运行后的应用包严格完整性校验通过。

视频剪辑的“导出预览 MP4”不会替用户生成分镜、样张和最终审片批准。代码动画的正式交付流程在临时测试项目里完成了技术验收用的批准，不代表用户对任何正式作品的创意签收。
