# 桌面端界面检查与修复（2026-10-29）

本轮围绕实际页面检查内容区尺寸、换行、下拉框、图标、弹层和滚动。检查使用隔离数据，未修改用户作品；测试素材来自已有素材库的只读连接。初次过早拍到的加载状态已作废，稳定后的对照保存在 `.tmp/desktop-ui-audit-20261029/before/`。

## 修复结果

| 问题 | 原因与修复 |
| --- | --- |
| 新建设计体系右侧表单被裁切 | 表单使用 `100vw`，未扣除应用侧栏。改用容器宽度，窄容器自动改为单列。 |
| 自动化卡片说明被截断 | 富内容卡片继承按钮的 `white-space: nowrap`。允许标题、说明换行，并让卡片高度随内容增长。 |
| 新建自动化关闭按钮为空白 | 32px 按钮继承左右各16px的内边距，图标被压缩到零宽。移除内边距，保留明确的关闭图标。 |
| 语言下拉框出现两个箭头 | 全局高层规则重新绘制箭头，覆盖了自带图标的控件。取消全局箭头覆盖，由各控件负责自己的箭头。 |
| 通用设置滚动不到底部 | 内容节隐式产生嵌套滚动并收缩。恢复自然高度，仅由设置主内容区滚动。 |
| 设计体系发布状态竖排 | 复选框继承通用输入框宽度，挤压旁边文字。固定复选框尺寸，发布标签保持单行。 |
| 影片工作区混入网页设计体系 | 视频／动画项目改为“动画风格”，使用动画风格目录。新影片不继承网页设计体系；已有网页关联保留在历史数据中，但不再注入影片创作上下文。 |
| 影片编辑重复导航过多 | 动画风格成为独立根视图，影片的方案子导航仅保留分镜／样张。参数面板默认收起，按需展开；风格视图去掉分镜条与重复的制作／审片导航。 |

动画风格选择会保留现有分镜。个人动画风格仍通过原有来源校验与素材复制接口复用；没有新增绕过授权的读取路径。原有人工确认分镜、样张、审片和交付的边界保持不变。
