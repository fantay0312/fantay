# Fantay translations

Application translations live in `apps/web/src/i18n/locales/`. Shared keys are declared in `apps/web/src/i18n/types.ts`. Follow the locale requirements in `AGENTS.md` when changing interface copy.

The current setup and maintenance documents are `README.md`, `QUICKSTART.md`, `CONTRIBUTING.md`, and `MAINTAINERS.md`. Language-specific entry pages in `docs/i18n/` link to these maintained documents.

Documentation changes should use the Fantay repository and distribution endpoints. Source attribution belongs with the inherited resource or in `THIRD_PARTY_NOTICES.md`.
