# Fantay 功能图标

Fantay Studio 导航入口用的 31 个功能图标：悬停时形变，在产品里画成线框极简风。两套线框色板按主题切换（`src/engine.js` 的 `FANTAY_INK`，Studio 跟随 `<html data-theme>` 即时切换），没有渐变、投影和顶部高光，所有线条和标记都是一种墨色：

- 浅色「Fantay 线框」：线条 `--ink #181818`，描边 1.5；白色内容和大面积纯色改为内侧描线；主体和内容填白，整张 SVG 以 darken 与背后混合，所以图标内部总是等于所在的表面（悬停、选中行也一样）。
- 深色「Fantay 线框 · 深色」：线条 `#EDEDED`，主体填 Studio 最深的页面色 `#181818`，以 lighten 混合。
- `data-line` 按图标微调线框，只有线框色板读取：`none` 隐藏会和别的线重叠的轮廓（信息内圈、拼图前片），`bare` 让白色内容不描线（闹钟表盘、剪贴板纸面、幻灯片画面），`ink` 把内容填成墨色（胶片齿孔）。
- 上一版黑白双色实心墨（`FANTAY_SOLID`，「Fantay 黑白」）留在展示页作对比。

引擎和 17 个图标来自 Kubai Icons，另外 14 个为 Fantay 新画：拼图、芯片、调节、烧瓶、信息、网页、胶片、幻灯片、台灯，以及个人助手 PA 的服务铃、机器人、机器人组、清单、插头。许可见 `LICENSE`。

## 图标与位置

| 位置 | 功能 → 图标 |
|---|---|
| 侧栏 | 新对话 → 聊天，主页 → 主页，全部项目 → 快捷方式，工作台 → 台灯，素材库 → 文件夹，插件 → 拼图，自动化 → 闹钟，社区 → 地球，已归档 → 包裹，设置 → 设置 |
| 设置 | 模型与提供商 → 芯片，指令与规则 → 剪贴板，记忆 → 笔记本，账户 → 用户，通用 → 调节，AI 用量 → 图表，实验室 → 烧瓶，隐私 → 盾牌，关于 → 信息 |
| 首页创作类型 | 网页/应用设计 → 网页，图片 → 照片，视频 → 视频，代码动画 → 胶片，社媒设计 → 手机，演示 → 幻灯片，文档 → 文档 |
| 个人助手 PA | 侧栏入口 → 服务铃；分区：助手 → 聊天，智能体 → 机器人，群组 → 机器人组，任务 → 清单，记忆 → 笔记本，连接与设置 → 插头 |

工作台的台灯：悬停时上臂绕肘部压低、灯罩向桌面低头，同时开灯，灯口下展开三道光线，停在低头亮灯的样子。

PA 的悬停动作：服务铃的按钮按到底、弹出两道声线；机器人眼睛弯成笑眼、天线上扬；机器人组两个一起笑；清单的空圈收起、第二项打勾；插头和插座对插到一起，接缝成一条线。助手和记忆沿用聊天、笔记本，与新对话、设置 · 记忆同义同图。折叠侧栏的 PA 按钮在 Lucide 控件行里，用同形的 `ConciergeBell`。

Studio 里的键名（`FeatureIcon name=`）见 `studio/apps/web/src/fantay/ui/feature-icon.tsx`。

## 文件

- `index.html`、`src/app.js`：展示页，打开 `index.html` 即可看全部图标，可切换色板、开演示。选深色色板（「Fantay 线框 · 深色」「Fantay 黑白 · 深色」）时整页切到 Studio 的深色（页面 `#181818`、格子 `#222222`），换回其他色板即回到浅色页面。
- `src/engine.js`：Kubai 引擎。Fantay 的改动都标了 `Fantay:`：纯灰主色的三个通道统一按红通道推导，深色标记不再偏紫；色板可以只给一个颜色（字符串）供所有图标共用；色板可带 `flat` 表（`paintFlat()`），按部件类别直接给颜色：后片、前片、描边、深色标记、浅一档标记、浅线、白色标记、白色内容、大面积纯色，并去掉投影和高光；再带 `line`（`paintLines()`）就画成线框：描边宽度、白色内容的内侧描线、整张 SVG 的混合模式；`recolor()` 让图标立即换到当前色板；`FANTAY_INK`（线框）、`FANTAY_SOLID`（黑白）和 `inkTone()`。
- `src/icons.js`：31 个图标的定义。保留的 Kubai 范例除 `data-line` 标记（闹钟、剪贴板）和闹钟的悬停外未改动。悬停动效都是一次到位、停在终点的动作，不做来回晃动：闹钟分针扫一圈、时针前进一小时（10:08 → 11:08），拼图被拿起时上提并倾斜。
- `scripts/check.mjs`：自检，在无头 Chrome 里截出静止、悬停、过程帧、24/28px 和各色板，输出到 `check-out/`。`palettes.png` 里每个色板画在自己的页面上（深色色板在深色格子上）；`--palette 名字` 让静止、悬停、过程帧和 24/28px 截图都用该色板（`palettes.png` 仍对比全部色板），深色色板连页面一起变深；色板名写错会在截图前报错退出，不覆盖已有截图。
- `scripts/export.mjs`：导出静态 SVG，默认「Fantay 线框」。线框的混合模式只在 SVG 内联进页面时生效，作为图片使用时主体是实色（浅色白、深色 `#181818`）。
- `scripts/sync-studio.mjs`：把引擎和图标写进 Studio 的 `apps/web/src/vendor/kubai-icons/runtime.ts`。

## 修改流程

```sh
node scripts/check.mjs --only 拼图 --with 文件夹,设置   # 改完先看截图
node scripts/check.mjs --palette "Fantay 线框 · 深色" --out check-out/dark   # 深色线框整套截图
node scripts/sync-studio.mjs                            # 再同步到 Studio
node scripts/export.mjs --palette "Fantay 线框" --out <目录>   # 需要静态 SVG 时；深色页面用 "Fantay 线框 · 深色"
```

增删图标后同步改 `src/app.js` 的 `ORDER`、`USES`，`index.html` 每个断点的列数要能整除图标总数（现在 31 是质数，没有能整除的列数：宽屏 8 列、720px 以下 4 列，末排都只差一格），再改 `feature-icon.tsx` 的键名表。
